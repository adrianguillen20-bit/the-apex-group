# The Apex Group — Landing Site

A one-page portfolio/landing website for The Apex Group.

## Brand
- Tagline: **AN EXPERIMENT IN THE EXCEPTIONAL**
- Primary background: `#0F1011`
- Charcoal: `#171819`
- Platinum/Silver: `#D2D0CB`
- Soft Silver: `#A9A7A2`
- Warm Stone: `#E9E5DE`
- Display font: Montserrat (Google Fonts)
- Body font: Inter (Google Fonts)

## Pages
- `/` — one-page public site
- `/client-login` — placeholder private client access page

## Local preview
Open `index.html` directly, or run any static server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Vercel
This is a static site and can be deployed directly to Vercel with no build command required.
